# PanaviBunga Store

Toko digital statis (HTML/CSS/JS) dengan OTP server-side (Vercel Serverless
Functions), Firebase Authentication (Email/Password + Google), Firestore,
dan pembayaran QRIS statis + verifikasi manual lewat WhatsApp.

Project ini dibangun menggunakan struktur, UI/UX, dan behavior **Aliftzy
Store** sebagai referensi/template, tetapi menjadi produk yang berdiri
sendiri: Firebase project baru, tanpa payment gateway, tanpa backend lama.

**Sebelum deploy, baca [`SETUP-PANAVIBUNGA.md`](./SETUP-PANAVIBUNGA.md)** —
berisi checklist wajib (ganti asset QRIS, isi nomor WhatsApp, konfigurasi
Firebase & environment variables Vercel).
